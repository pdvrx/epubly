Epubly OPDS recomendado

Configure uma vez no KOReader: cada conversão entra sozinha na sua estante e fica disponível por 48h. Seu código pessoal garante que só você veja o que converteu.

  1. No KOReader: Busca de livros → Catálogos OPDS → +
  2. Nome: Epubly
  3. URL: https://epubly-worker.pedro06bf.workers.dev/opds?code=
  4. Salve. Após cada conversão o livro aparece automaticamente no catálogo

O código é armazenado apenas no seu navegador e identifica seus livros. Nenhum dado pessoal é compartilhado.

Sobre o projeto

O que é o Epubly?

Ferramenta gratuita e de código aberto para converter PDFs em EPUB.

A iniciativa
Milhares de obras raras existem apenas como scans de baixa qualidade.
Como funciona
O PDF é renderizado direto no navegador e as imagens vão para a IA.
Código aberto
Todo o código está disponível no GitHub.
Por que as doações são fundamentais
Cada conversão tem um custo real de IA. Sem doações o projeto precisa fechar.
